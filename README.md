# 🎮 Number Guessing Game (C++)

A console-based Number Guessing Game developed in C++.

## Features
- Random number generation
- 10 attempts
- Score calculation
- Performance rating
- Play Again option
- Input validation

## Concepts Used
- Loops
- Conditional Statements
- Random Numbers (rand)
- User Input
